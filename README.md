# Happiest Birthday, My AMMA 🎂❤️

A special, interactive birthday website made with love for Amma.

## ✨ Features

- **Interactive Experience**: Fullscreen birthday celebration experience with dynamic animations and sound.
- **Photo Memories**: 3D Coverflow carousel and interactive lightbox photo gallery.
- **Heartfelt Letter**: Custom heartfelt birthday note and balloons celebration.
- **Ready for Vercel**: Fully configured with `index.html` and `vercel.json` for one-click deployment.

## 🚀 Deployment on Vercel

1. Push or import this repository on [Vercel](https://vercel.com).
2. Set Framework Preset to **Other** (Static Site).
3. Root Directory: `./`
4. Click **Deploy**!

Your site will immediately be live and accessible on any device.

## 💻 Local Testing

Open `index.html` or `papu bday.html` in any modern web browser, or serve locally with:

```bash
npx serve .
```
